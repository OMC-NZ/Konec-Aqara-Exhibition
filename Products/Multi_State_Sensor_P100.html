Product Info

Description

The Aqara Multi-State Sensor P100 Kit offers two versatile monitoring modes—Open/Close or Object Monitoring (one active at a time for optimal accuracy). It delivers fast, reliable detection of orientation, movement, falls, vibration, and open/close events.


With support for Zigbee and Thread, it integrates seamlessly with Apple Home, Alexa, Google Home, SmartThings, and Home Assistant. Self-calibration, adaptive learning, adjustable sensitivity, and clear event logs all work together to reduce false alerts, extend battery life, and keep your smart home running smoothly and reliably.


Key Features

  • Object Monitoring*: Track orientation, movement, falls, and vibration with precision. The sensor instantly reports changes to trigger alerts or automations. Customise which events to monitor and build smart routines based on object position or stability—ideal for security, asset protection, and everyday convenience.
  • Open/Close Monitoring**: Accurately detects every open and close event across doors, windows, fridges, safes, and more. Its compact, single-body design allows flexible placement, while enabling automations based on status and duration.
  • Dual-Protocol with Matter Compatibility: Supports both Zigbee and Thread. Use Zigbee mode for advanced Aqara Home features, or Thread for Matter integration with Apple Home, Alexa, Google Home, SmartThings, and Home Assistant—ensuring a flexible, future-ready smart home.
  • Calibration & Self-Learning: Automatically calibrates to its environment and continuously refines accuracy over time. Intelligent self-learning corrects drift and reduces false alerts, keeping performance reliable without manual adjustments.
  • Customisable Sensitivity Levels***: Fine-tune sensitivity and reporting intervals to suit your needs. Reduce unnecessary alerts, conserve battery life, and maintain precise monitoring for a smoother experience.
  • Event Logs & Statistics: Access detailed logs and visual charts of all activity. Quickly review historical data for doors, windows, and objects to spot patterns or unusual behaviour at a glance.
  • Protective Case for Outdoor Use: Includes a specially designed protective case for outdoor monitoring. Perfect for tracking mailbox activity, securing garden gates, or monitoring valuable outdoor items with confidence.

Note:
* Object Monitoring is available only in Zigbee mode via the Aqara Home app.
** Only one mode can be active at a time; Object Monitoring and Open/Close Monitoring cannot run simultaneously.
*** Sensitivity adjustment is available only in Object Monitoring mode.
